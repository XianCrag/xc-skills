# Skills

LLM-friendly skills. Each skill is a folder containing a `SKILL.md` with YAML frontmatter (`name`, `description`) and markdown instructions.

```
xc-skills/
└── <skill-name>/
    └── SKILL.md
```

| Skill | Description |
|-------|-------------|
| [lynch-stock-categories](lynch-stock-categories/SKILL.md) | Classifies a stock into one of the six stock categories, from Peter Lynch's *One Up on Wall Street*, Chapter 7; shared by the other Lynch skills |
| [lynch-stock-checklist](lynch-stock-checklist/SKILL.md) | Checklist for evaluating a stock, from Peter Lynch's *One Up on Wall Street*, Chapter 15 |
| [lynch-perfect-stock](lynch-perfect-stock/SKILL.md) | Scores a stock against the thirteen attributes of the "perfect stock", from Peter Lynch's *One Up on Wall Street*, Chapter 8 |
| [lynch-stocks-to-avoid](lynch-stocks-to-avoid/SKILL.md) | Tests a stock for the six warning types in "Stocks I'd Avoid", from Peter Lynch's *One Up on Wall Street*, Chapter 9 |
| [lynch-buy-sell-timing](lynch-buy-sell-timing/SKILL.md) | Judges whether now is a good time to buy or sell a stock, from Peter Lynch's *One Up on Wall Street*, Chapter 17 |
